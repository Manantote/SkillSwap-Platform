SkillSwap Platform

Project Requirements Specification

3.1 Software Requirements

Frontend Technologies:

  • Markup & Styling: HTML5, CSS3, JavaScript (Vanilla)
  • UI Framework: Bootstrap 5 (Responsive Layouts, Grid, Components)
  • Iconography: Bootstrap Icons
  • Typography: Google Fonts (Inter, Playfair Display)

Backend & Database:

  • Server-Side Scripting: PHP 8.x
  • Database Management System: MySQL / MariaDB
  • Local Development Environment: XAMPP Server (Apache & MySQL hosting)

Authentication & Integrations:

  • User Authentication: Firebase Authentication (Email/Password, Google OAuth)
  • Video Conferencing: Google Meet API (Persistent session links)

Development Tools:

  • IDE/Code Editor: Visual Studio Code
  • Testing Environments: Google Chrome, Safari, Mozilla Firefox
  • Version Control: Git

3.2 Hardware Requirements

Server-Side (Development Environment):

  • Processor: Intel Core i3 / AMD Ryzen 3 or higher (Apple Silicon M1/M2 supported)
  • RAM: Minimum 4 GB (8 GB recommended for optimal IDE and XAMPP performance)
  • Storage: Minimum 500 MB of free disk space for project files and database instances
  • Operating System: macOS (Current), Windows 10/11, or Linux

Client-Side (End-User Environment):

  • Device: PC, Laptop, Tablet, or Smartphone
  • Processor: Standard minimum requirements to run a modern web browser
  • RAM: Minimum 2 GB (4 GB recommended for smooth experience)
  • Display: Minimum resolution of 320px width (Mobile-responsive UI supported)
  • Network: Active broadband/4G/5G internet connection required for real-time chat, API requests, and Google Meet video sessions.
